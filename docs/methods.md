# 七条验证协议

> 这不是提示词技巧，而是**可执行、带判据、能自动跑的检查**。
> 每一条都对应一次真实的翻车事故——协议不是形式主义，是把"人工追问三次才补上的动作"固化成机器动作。

| # | 协议 | 判据（不通过怎么办） | 事故来源 |
|---|---|---|---|
| P1 | 双路径交叉 | 同一结论用两种**独立**方法实现（解析式 / 数值优化 / 仿真），相对误差 < 1e-9；不通过则查哪一路写错，两路都留进台账 | 闭式解与半平面交互相印证 |
| P2 | 细步重扫 | 凡出现"恒成立 / 一定 / 总是 / 从无例外"：步长细化 ≥10× 重扫，**并主动构造最坏构型**；不通过则结论降级为"在该步长下成立"并标未知 | 3° 步长整段跳过宽仅 2° 的违例带，输出"恒成立"的假结论；0.1° 细扫后最大越界比 1.0343，结论被推翻 |
| P3 | 连续复核 | 离散网格算出的极值必须用连续/自适应搜索复核，差异以**区间**报出，禁止报单点 | 网格峰值 0.0224174 vs 连续上确界 0.0224500，窄峰宽不足 0.5%；固定网格会把很小的正数误报成 0 |
| P4 | 极限与量纲 | 参数 → 0/∞/临界值时应退化为已知结果，量纲自洽；不通过则公式错，回上一步 | 参数取临界值时判据恰好取等，可用于反查公式 |
| P5 | 反例搜索 | **主动搜**使结论翻转的参数区域，报"翻转边界"（哪个参数、翻转点在哪）；找不到也要写明搜索范围与未覆盖区域 | 外环相位偏移半步即可让"零盲区"变成相反结论 |
| P6 | 口径声明 | 每个数字标：来源 / 定义 / 适用边界 / 能否外推；有分歧的**两套都算** | 自建仿真的虚拟时间与官方测试数字量纲与案例分布都不同，差点填进同一张表比较 |
| P7 | 台账对账 | 对外每个数字都能由一条命令从原始数据重算，**禁止手抄**；不通过则删掉手写数字，改为读 JSON | 所有统计值必须由脚本产 JSON、报告读 JSON |

## 三条原则

1. **"未触发"必须显式写出来**。没有出现"恒成立"类断言，不等于不用检查——是**检查了才发现不需要 P2**。
   留空 ≠ 通过，留空只是没人知道你到底做没做。
2. **"未覆盖"必须显式写出来**。搜不到反例时，写清搜索范围与没覆盖的区域，而不是写"未发现反例"。
3. **被证伪的结论要留痕**。删掉错误结论等于让同一个错误再来一次；台账里 `refuted` 是资产不是污点。

## 为什么门槛在 P2 / P3 / P5

P1 / P4 / P6 / P7 检查的是"**算得对不对、说得清不清**"——做得到的人多。
P2 / P3 / P5 要求的是"**主动去找自己的错**"，而且要在结论看起来很漂亮的时候去找。
这需要的是**对抗自己的意愿**，不是算力。工具的价值主要在这三条。

## 怎么在一个新问题上用

1. 先把结论按"承重"排序：哪几条结论一旦错，整个交付物就废了。
2. 每条承重结论至少跑 2 条协议，**P1 必跑**。
3. 出现全称量词（"恒 / 一定 / 总是 / 从无"）→ 立刻上 P2。
4. 报出任何极值 → 立刻上 P3，报区间。
5. 交付前强制写"失效边界"章节，内容只能来自证伪记录，不许自由发挥。
